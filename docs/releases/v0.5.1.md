## Dark Park v0.5.1 - Fixes

- **No more crash when jumping nights.** Using the Testing menu's night buttons (or restarting a night) could hang the game with an endless flood of errors. Fixed.
- **The end-of-night screen works with the mouse.** After you walk out of the booth the cursor stayed locked, so you couldn't click NEXT NIGHT. It's free now.
- **Much lighter paper stains.** Rain-damaged ID cards and lists are now just a few faint marks, easy to read.
- **NightLink has to be installed.** On night three it's no longer on the desktop from the start. Find the leaked memo, visit the hospital's website (www.ashfordgeneral.org), download MediCare Remote, and run it. Then NightLink appears.
- **NightLink window layout fixed.** Nothing overlaps any more.
- **Login screen gives no hints** on the hospital gateway.

Everything from v0.5.0 (selectable dialog, the night three hospital hack, the night two touches) is included.

### Install
Download `DarkPark-windows.zip`, unzip it anywhere, and run `DarkPark.exe` from inside the folder. Your saves carry over.
